# Brasil, 24 anos

Estudo com fontes oficiais: o Brasil de 2002 a 2026 comparado a 19 países, estado por estado e ano a ano.

- `index.html`: site estático (Chart.js via CDN). Os dados estão embutidos no `<script id="data">`.
- `data/wb.csv`: séries do Banco Mundial (20 países, 2002–2024).
- `data/uf.csv`: indicadores por UF (IBGE, PNUD, Ipea/FBSP) com link da fonte em cada linha.
- `data/fontes.md`: todas as fontes com data de leitura.
- `data/site_data.json`: dados derivados que alimentam a página.

Material de estudo. Não é publicação de órgão público.
